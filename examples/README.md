# 示例数据

这里是一套可以直接运行的演示模板，包含三个业务：

- `公务卡申请`：Word 申请表 + Excel 信息登记表
- `信用卡激活`：Word 激活申请表
- `降额`：Word 额度调整申请书

## 运行方式

1. 启动 DocFill。
2. 模板根目录选择本目录下的 `templates`。
3. 输出根目录选择本目录下的 `output`（可自动创建）。
4. 选择业务，点击“智能粘贴解析”，粘贴：

```text
姓名：张三
身份证号：360700199001011234
手机号：13812345678
单位：某某科技有限公司
地址：江西省赣州市章贡区红旗大道123号
申请日期：2026-10-18
```

5. 确认填充后点击“一键生成文档”。

> 示例中的姓名、证件号码、手机号、单位、地址均为虚构数据，不对应任何真实个人或机构。
