# DocFill 1.0.2 - 使用说明

## 一、项目简介

本工具用于在内网离线环境下，批量填充 Word/Excel 模板中的变量，生成业务文档。
- 完全离线运行，不依赖任何网络服务
- 填充流程只读取原始模板，结果写入独立输出目录；仅“统一变量名”会在二次确认并自动备份后修改模板
- 支持智能粘贴：粘贴一段文本自动识别字段并填充
- 支持多人批量生成：一次粘贴多人信息，逐人生成文档
- 支持变量表达式（如从身份证号截取出生日期）
- 支持日期格式设置：输入 `20260101`，可输出 `2026年1月1日` 等格式

> 第一次用：点右上角 **【使用教程】**，按“选两个文件夹 → 粘贴资料 → 一键生成”三步走即可。

---

## 二、快速开始（exe 版，推荐）

**无需安装 Python，双击即用。**

1. 把 `DocFill.exe` 放到任意文件夹（如桌面或 D 盘某目录）。
2. 双击运行，首次启动会自动在同目录生成 `config/` 配置文件夹。
3. 点击 **【选择模板根目录】** 和 **【选择输出根目录】** 各设置一次（以后自动记住）。
4. 界面右上角有 **【使用教程】** 按钮，点击可随时查看图文教程。

> 常见问题：若双击无反应或闪退，查看 exe 同目录的 `error.log`。

### exe 同目录文件说明

| 文件/目录 | 说明 |
|-----------|------|
| `config/settings.json` | 用户设置（模板/输出目录、日期格式、变量排序、客户名/身份证变量、快捷键等），自动生成 |
| `config/aliases.json`  | 变量别名映射，首次运行自动释放，用户新增的别名会保存在这里 |
| `error.log`            | 仅程序异常时生成，排查问题用 |

### 高级：自定义识别规则/默认值/地址字典（可选）

在 exe 同目录手动放入以下文件即可**覆盖内置版本**（不放则用内置默认）：

| 外置文件 | 作用 |
|----------|------|
| `config/rules.json` | 智能粘贴识别规则（正则） |
| `config/defaults.json` | 各业务变量的默认值/表达式 |
| `data/region_dict.json` | 地址解析用的省市区字典 |

## 三、GUI 界面操作

启动后界面分为四部分：

### 1. 顶部：路径配置
- **模板根目录**：存放模板的文件夹，其下每个一级子文件夹 = 一项业务
- **输出根目录**：生成文档的存放位置（与模板隔离，不会修改模板）
- **重名策略**：
  - 追加序号（默认）：`申请表.docx` → `申请表_1_1234.docx`（1234 为身份证后四位）
  - 覆盖：直接覆盖已有文件
  - 跳过：已存在则不生成
- **使用教程**：内置图文教程
- **设置**：日期格式、变量表排序、客户名/身份证变量、快捷键、本机缓存清理

### 2. 左侧：业务列表
- 点击"刷新业务列表"（F5）扫描模板根目录
- 点击业务名称，右侧自动加载该业务的所有变量

### 3. 右侧：变量操作
- **变量表格**：单击"值"列单元格即可编辑，支持表达式（见第六节）；空值以浅黄色高亮
- **变量表排序**：默认按模板填写顺序；可在【设置】中切换为字典顺序
- **智能粘贴解析**（Ctrl+Shift+V）：粘贴一段文本自动识别字段，并显示模板覆盖情况（见第五节）
- **应用上次数据**（Ctrl+R）：同一客户办多个业务时，一键复用上次粘贴的内容；数据保存在本机，重启后仍可用
- **统一变量名**：将模板中不一致的变量名（如"客户名称/客户名"）统一为标准名（会修改模板文件；修改前自动备份，可点“撤销上次统一”恢复）
- **新增/删除自定义变量**：模板变量不可删，仅自定义变量可删
- **CSV导入**：自动识别 UTF-8 / GBK，导入前预览并可选表头（格式：`变量名,值`）
- **CSV模板**：导出当前业务的变量名模板，方便在 Excel 中填写
- **整列粘贴**：从 Excel 复制一列值，选中变量表起始行后 Ctrl+V，可批量填入；也支持“变量名 + 值”两列
- **一键生成文档**（Ctrl+G）：生成前检查空变量和“未知客户”，确认后生成所有模板文档；模板较多时显示进度，可取消
- **下一单（清空）**：清空当前变量值，开始下一位客户；也可在【设置】中开启“生成成功后自动清空”
- **输出目录防护**：输出目录不能选在模板目录里面，程序会在选择时拦截
- **窗口大小**：会自动记住上次的窗口大小和位置；小屏会自动缩小到可用区域

### 4. 底部：操作日志
显示每一步操作的结果和错误信息。

## 四、制作模板

1. 在 Word（.docx）或 Excel（.xlsx）中，把需要填写的位置写成 **`{{变量名}}`**，
   例如：`{{姓名}}`、`{{身份证号}}`、`{{日期}}`。
2. 可选变量写成 **`{{变量名?}}`**，例如 `{{备注?}}`。可选变量为空时不会阻止生成。
3. 同类模板放进模板根目录下的**同一个子文件夹**，子文件夹名就是"业务名"。
4. 支持 `.docx` / `.xlsx` / `.wps` / `.et`（新版 WPS 格式）。
5. 正文、表格、页眉页脚段落和页眉页脚表格都支持；文本框做基础替换，复杂文本框建议先把变量放到正文。
6. 模板文件夹有变动后，点"刷新业务列表"或按 F5 重新扫描。

## 五、智能粘贴使用

1. 点击"智能粘贴解析"按钮（或 Ctrl+Shift+V）
2. 将原始业务文本粘贴到输入框（支持多行）
3. 点击"智能解析"，系统自动识别姓名、身份证号、手机号、日期、单位、地址（自动拆省市区）等字段
4. 可双击修改值、删除不需要的字段、新增字段
5. 未识别的片段在"待确认区"，可手动指定归属变量
6. **多人模式**：粘贴多人信息（每人一段，空行分隔，或用独占一行的 `---` / `===` 分隔），确认后逐人批量生成文档。每个人使用独立变量，不会带入上一位客户的数据。
7. 点击"确认填充"，结果回填到主窗口的变量表格

**示例粘贴文本：**
```
姓名：张三
身份证号：360700199001011234
手机号：13812345678
单位：某某科技有限公司
家庭住址：江西省赣州市章贡区红旗大道123号
```

> 提示：粘贴文本尽量"一行一项"，识别率最高。

## 六、变量表达式

变量值支持表达式，常用函数：

| 函数 | 说明 | 示例 |
|------|------|------|
| `substr(变量, 起始, 长度)` | 截取子串 | `substr(身份证号, 6, 8)` → `19900101` |
| `concat(a, b, ...)` | 拼接 | `concat(姓, 名)` |
| `split(变量, 分隔符, 索引)` | 拆分取段 | `split(地址, "省", 0)` |
| `replace(变量, 旧, 新)` | 替换 | `replace(电话, "-", "")` |
| `trim(变量)` | 去首尾空白 | |
| `len(变量)` | 字符串长度 | |
| `today()` | 当前日期 | `2026-10-16` |
| `year()` / `month()` / `day()` | 当前年/月/日 | |
| `int(值)` / `str(值)` | 类型转换 | |
| `regex_extract(变量, 正则, 分组)` | 正则提取 | |

变量之间可互相引用，例如 `出生日期` 设为 `substr(身份证号, 6, 8)`，
只要填写了身份证号，出生日期会自动计算。

默认值配置在 `config/defaults.json`，按业务分组，支持表达式。

## 七、日期格式

日期在程序内部统一保存为 `YYYY-MM-DD`，只在写入文档时按设置转换，所以改格式不会影响 `substr` 等表达式。

在右上角 **【设置】** → **日期格式** 中选择：

| 格式 | 示例 |
|------|------|
| `YYYY年M月D日` | 2026年1月1日（默认） |
| `YYYY年MM月DD日` | 2026年01月01日 |
| `YYYY-MM-DD` | 2026-01-01 |
| `YYYY/MM/DD` | 2026/01/01 |
| `YYYYMMDD` | 20260101 |
| `M月D日` | 1月1日 |

起止日期的连接词可选“至 / 到 / ~ / —”。例如输入 `20260101-20260330`，模板里的开始时间、结束时间会自动填充，并按设置输出为 `2026年1月1日至2026年3月30日`。

> 只有字段名包含“日期 / 时间 / 出生 / 起始 / 截止 / 起止”等关键词时才按日期处理，项目编号等 8 位数字不会被误改成日期。

## 七点五、版式保护与溢出缩字号

Word 模板最怕“本来刚好一页，填完最后一行跳到第二页”。DocFill 默认用**版式保护渲染**：只替换文字节点，不动任何字体、段落、表格、页面属性，所以只要数据长度没超过格子容量，页数不会变。

唯一例外是你授权的**自动缩小溢出单元格字号**：当真实数据比占位符长、格子里必然多占行时，程序会把该单元格字号适度调小以保住页数。

- 只在确实会多占行时才触发，能放下就绝不缩；
- 最多缩到原字号的 70%，再长也不缩成蚂蚁字（此时保持可读下限并记录日志）；
- 每次调整都会写进操作日志，例如 `第3行：14→11 磅（防溢出）`；
- 在 **【设置】** 里勾选/取消 **“内容超出格子时自动缩小字号”** 即可开关；关闭后一个字都不动。

> Excel 不受此机制影响，它针对 Word 表格。

## 九、命令行模式（可选）

exe 也支持命令行参数（在 cmd/PowerShell 中运行）：

```bash
# 设置模板根目录 / 输出根目录
DocFill.exe --set-template "D:\模板"
DocFill.exe --set-output "D:\输出"

# 列出所有业务
DocFill.exe --list

# 交互式命令行模式
DocFill.exe --cli
```

> 注意：exe 版默认隐藏控制台，命令行输出不可见属正常现象；需要查看输出时请从源码运行（见附录）。

## 十、常见问题

**Q1：双击 exe 没反应 / 闪退**
A：首次启动需解压几秒，请稍等；仍失败则查看 exe 同目录的 `error.log`。
部分杀软可能误报，添加信任即可。

**Q2：生成的文件在哪？**
A：输出根目录下的 `业务名_客户名_年月` 子文件夹中。客户名会按“设置的客户名变量 → 客户名 → 姓名 → 单位”自动兜底；生成完成后弹窗可直接“打开输出目录”。

**Q3：生成的文档中变量没被替换**
A：检查模板中变量标记是否为 `{{变量名}}` 格式（变量名需与表格中的变量名完全一致）。生成前如果还有空变量，程序会弹出检查提示，未填位置会留空。

**Q3-1：备注等可选字段为空也会被提示？**
A：把模板里的 `{{备注}}` 改成 `{{备注?}}`，它就会作为可选变量，不再出现在必填提示里。

**Q4：重名文件没有追加身份证后四位**
A：需要在变量中填写"身份证号"字段，否则只追加序号。

**Q5：智能粘贴识别不准**
A：粘贴文本尽量一行一项（如"姓名：张三"）；高级用户可在 exe 同目录放
`config/rules.json` 覆盖内置规则。

**Q6：地址没有拆出省市区**
A：内置字典目前只含江西省。可在 exe 同目录放 `data/region_dict.json` 补充其他省份。

**Q7：换电脑/重装后配置还在吗？**
A：配置保存在 exe 同目录 `config/` 下，整个文件夹拷贝过去即可。

**Q8：为什么输出目录是“未知客户”？**
A：说明当前业务没有取到客户名。请确认模板里有 `{{客户名}}` 或 `{{姓名}}`，或在 **【设置】→ 输出命名** 中选择正确的客户名变量；生成前程序也会提示。

**Q9：日期格式怎么改成“2026年1月1日”？**
A：在 **【设置】→ 日期格式** 中选择 `YYYY年M月D日`（默认），也可以自定义格式。起止时间会自动按同一格式输出，不需要手动再输一遍。

## 附录：从源码运行（开发者）

环境要求：Python 3.11 64位 + PySide6、python-docx、openpyxl

```bash
git clone https://github.com/daokunn/docfill.git
cd docfill
python -m venv .venv
# Windows: .\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main.py            # GUI 模式
python main.py --cli      # 命令行模式
```

重新打包 exe：

```bash
pip install -r requirements-dev.txt
python -m PyInstaller build.spec --noconfirm
# 产物在 dist/ 目录
```

目录结构：

```
docfill/
├── main.py                      # 程序入口（GUI/CLI 双模式）
├── app_paths.py                 # 打包路径适配（exe/源码通用）
├── build.spec                   # PyInstaller 打包配置
├── config/                      # 配置：settings/rules/defaults/aliases
├── core/                        # 核心：扫描/变量/表达式/解析/渲染
├── output/                      # 文件输出与日志
├── ui/                          # 界面：主窗口/智能粘贴/样式与教程
├── data/region_dict.json        # 省市区字典
├── examples/                    # 演示模板与输出
├── docs/                        # 使用说明与界面截图
└── tests/                       # 测试脚本与测试模板
```
